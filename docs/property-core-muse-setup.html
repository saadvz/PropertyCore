Property Core · Muse guide

Set up Property Core in Muse

Property Core runs your rental's jobs from one chat, property by property. Cleaner Core texts your cleaner about each turnover and hands over the door code once the guests have left. Supply Core keeps the place stocked: you pick each product once, Muse shops in its own browser, and every cart is checked before checkout.

You don't need any technical skills. Pick a flow to see its steps, then follow them in order.

About 20 minutes5 stepsAbout 20 minutes, more for a long list5 stepsStarts with one paste

Which flow are you setting up?

A property can run both. Set up one now, and turn the other on later by asking Muse.

Fixer Core, for repairs, is offered only where the service has FIXER_CORE=1. Self-guided tours (Tour Core) are on hold for new hosts, and Saad sets them up by hand. Their guide is here.

Stuck at any point? That's normal. Two easy ways out:

1. In your Muse chat, type "I'm stuck on step 2" (or whichever step) and describe what you see. Muse will walk you through it.

2. Or text Saad the step number and what the screen says. A screenshot helps, as long as it doesn't show a door code, a card, or a secret code.

Before you start

Have these ready. If one is missing, a step will stop partway through.

Your Meta account

A Muse account

Muse needs a payment card on file, even on the free tier. Each check Muse makes counts toward your usage.

Your phone, or Saad

A way to sign in

Where sign-up is open, you create an account with a code texted to your phone. Otherwise Saad sends an invite code. It only works once, and only for 7 days.

You type these during setup

Two phone numbers

Your mobile number and your cleaner's. With both, you get a group chat with your cleaner. Only have one number? Enter it as the cleaner's number too, and you get a chat with the assistant instead.

Your own details

Property basics at hand

Your property's address, usual checkout and check-in times, your cleaner's name, and your door code.

Each store you'll use

A store account with a way to pay

You sign in yourself, in Muse's browser. The account needs its payment method saved. Supply Core never sees your card.

Your own details

Your shopping list

The property's address and everything you want restocked, up to 30 items.

A few words you'll see

Here's what they mean. You don't need to understand more than this.

Property Core
The add-on that connects Muse to Cleaner Core and Supply Core. Muse adds it for you.
Flow
One job Muse runs at a property: Cleaner Core or Supply Core. A property can run both.
Choice card
Buttons Muse shows for a question. Tap one to answer.
Muse's browser
A web page Muse opens and hands to you. You type in it yourself, so secrets stay private.
Recurring task
A helper Muse makes that checks for news on a schedule.
Held cart
A cart Supply Core stopped before checkout, like a price jump or a cart over your cap. Nothing is bought until you say yes.

The steps for Cleaner CoreSupply Core

Tick "Done" as you finish each step. The ticks are remembered in this browser, so you can take a break and come back.

1

Paste the setup message

Muse chat
  1. Open Muse and start a new chat.
  2. Click Copy message below, then paste it in Muse's message box and send it.
  3. Muse starts working. This can take a few minutes.
See the message you're pasting
Set up Property Core for my short-term rental using the open-source repository at https://github.com/saadvz/PropertyCore.
Use your cloud computer to clone the repository only so you can read its setup instructions. Save the folder property-core-template/muse/skills/property-core as a skill named Property Core, then follow its SKILL.md as the authoritative setup instructions. Do not start anything on your computer.
Create the Property Core connector at the hosted service's /mcp yourself. When the connection asks for approval, hand me the approval page so I can sign in or type my invite code from Saad and click Allow. Never ask me for the invite code in chat, and never click Allow yourself.
As soon as you're connected, call get_state. Add my property, then ask which flows I want there, Cleaner Core, Supply Core, or both, as a choice card. Then follow each flow's skill one question at a time.
Never ask me to paste API keys, passwords, tokens, calendar links, card details, or door codes into chat or a card. When a secret is needed, open the service's private page in your browser and hand the browser to me, so I type it there myself.
Start now.

It looks technical, but you don't need to read it. It tells Muse where to find the setup instructions.

Connect your account

Muse's browserMuse settings
  1. A page titled Connect Muse to Property Core opens in Muse's browser, and Muse hands it to you. Sign in, or create an account with the code it texts to your phone. If it only asks for an invite code, type the one Saad sent you.
  2. Click Allow yourself. Muse isn't allowed to do this part.
  3. Open Settings → Connectors → Property Core and let Muse use it without asking each time. This lets the checks run while you're away.

Only if your bookings are on a Google calendar: connect Muse's Google Calendar connector too.

3

Answer Muse's questions

Muse chatMuse's browser
  1. Give Muse your property's address. It asks which flows to turn on there. Tap Cleaner Core, or both. Have more than one property? Add each one the same way.
  2. Muse asks one question at a time. When it shows buttons, pick one. Otherwise answer in your own words. It will ask about:
    1. Your property: its name, address, and usual checkout and check-in times.
    2. Where your bookings are (Guesty, Google Calendar, Airbnb and so on).
    3. Who's involved: your mobile number and your cleaner's number. Two numbers set up a group chat with your cleaner. If you only have one number, give it as the cleaner's number too, and you'll get a chat with the assistant.
    4. Timing: how early to offer each cleaning, when to remind, and hours not to text.
    5. Your door system, then your door code.
    6. Your cleaning checklist and anything else you prefer.
  3. For your door code, Muse opens a private page in its browser and hands it to you. Type the code there and click Save.
  4. For a calendar link, pick I have the link and paste it on the page Muse hands you, or Find it for me and sign in to your booking site yourself when asked.

Not sure how to answer? Just say so. "I don't know, what do most people pick?" works fine.

Turn it on

Muse chat
  1. Muse shows a summary of everything you told it. If it all looks right, type Activate. If something's wrong, say what to change first.
  2. Muse asks about times for your next booking. Say "use my usual times", or give the times for that booking.

3

Answer Muse's questions

Muse chat
  1. Give Muse the property's address. Supplies are delivered there. When it asks which flows to turn on, tap Supply Core, or both. If Muse says Cleaner Core has to be on first, pick both.
  2. Muse asks one question at a time. It will ask about:
    1. Your list: everything you want restocked, up to 30 items. It reads the list back once.
    2. Where to buy: stores that deliver to the door, like Walmart, Target, or Costco. Maybe also a same-day service, like Instacart, for rush orders.
    3. Schedules: one for everything, or one per item. Every so many days, a day of the month, or once every so many stays.
    4. A product for each item. Tap your pick from the products Muse shows. Then a backup if you want one, and how many to buy each time.
    5. Your booking calendar, only if an item goes by stays and none is saved yet. You paste the link on a page Muse hands you.
    6. Hands-off ordering, or stop at checkout for your yes.
    7. Spending caps: per order, per month, both, or none.
    8. The check time for the daily check. 10:00 unless you pick another.

Not sure how to answer? Just say so. "I don't know, what do most people pick?" works fine.

The daily check and your stores

Recurring taskMuse's browser
  1. Muse makes a recurring task called Supply Core by itself. It runs every day at your check time. You don't copy anything.
  2. Muse opens each store in its browser, without ordering. If it isn't signed in, it hands you the browser. Sign in yourself, including any code the site texts or emails you.
  3. The account's delivery address should be your property's, and a payment method must be saved. If one is missing, Muse hands you the store's payment page to add it there.

Never type a password or card number in the chat. You type them only on the store's own page.

What happens from now on

Most days you don't need to do anything. You hear when something needs you.

Group text

Your cleaner texts

You see their message right away in the group text. Muse picks it up at its next check. To reply, tell Muse "Maria texted, draft a reply".

Door code

The code waits for your yes

Your cleaner only gets the door code after you've said the guests have left.

Summary

Cleaning finished

Your assistant looks at the cleaner's photos, checks them against your checklist, and sends you a short report.

Every day

Muse checks what's due

At your check time, the Supply Core task finds what's due and shops for it in Muse's browser.

Checkout

Every cart is checked

Before any order, Supply Core checks the final cart: the items, the total, and the delivery date. If it passes, Muse orders and tells you. A held cart waits for your yes: buy anyway, use the backup, or skip.

Store account

Your cards stay yours

Card details never reach Supply Core. Muse pays with the method saved on the store account. If a store asks for a sign-in or a card code, Muse hands you the browser.

Any time

Running low?

Say "we're low on paper towels". With Cleaner Core too, your cleaner's "running low" answer after a cleaning turns into an order.

If something goes wrong

Click a problem to see what to do.

It says my invite code "isn't right", "has expired", or "was already used"

Each invite code works only once, and only for 7 days.

What to do: text Saad for a new code, then connect again.

I picked the wrong flow, or want to add the other one

You can change it any time.

What to do: tell Muse "turn on Supply Core" or "turn off Cleaner Core". If anything is live, it shows what stops and waits for your yes. Your setup is kept.

Muse says to start a new chat, or can't find the right tools

New tools only show up in a fresh chat.

What to do: start a new chat and say "Set up Property Core". Your answers so far are saved.

Setup is finished but my cleaner never got a text

Usually the next booking's times aren't confirmed yet.

What to do: tell Muse "confirm the times for the next booking". If it says nothing was sent, text Saad.

Muse says a store needs me

The store asked for a sign-in or a card code. Muse never types those.

What to do: in a chat with Muse, take the browser it hands you and type it there yourself. A daily run tries once more the next day.

Muse says a cart is held

Something changed, like a price jump or a cart over your cap. Nothing was bought.

What to do: answer in the chat: buy anyway, switch to the backup, or skip.

Muse warns it hasn't checked in

Usually Muse is waiting for an approval nobody saw.

What to do: check Settings → Connectors → Property Core is set to not ask each time. Then ask Muse to turn the task back on.

Muse is using more of my usage than I'd like

What to do: tell Muse "check less often, every hour".

Muse asks me to type a door code or password in the chat

It shouldn't. What to do: reply "please open the private page in your browser for me instead".

Anything else

What to do: type "I'm stuck" in the chat and describe what you see, or text Saad the step number and what the screen says.

When you ask Saad or anyone else for help, never send a door code, your invite code, a card number, or any secret code from setup.
